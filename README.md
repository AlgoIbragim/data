# ИнфоТренер — интерактивный тренажёр по информатике

Веб-приложение с ролями ученика и преподавателя: регистрация, тесты, таймер, разбор ответов и админка.

## Запуск локально

1. Установите зависимости: `pip install -r requirements.txt`  
   Если Python запрещает установку в систему: `python -m venv .venv`, активируйте окружение и повторите команду.
2. Запустите сервер: `python app.py`
3. Откройте в браузере: [  ](http://127.0.0.1:5000)

Демо-вход: ученик `student` / `Student123`, преподаватель `teacher` / `Teacher123`.

Пароль при регистрации: не меньше 8 символов, цифра, строчная и заглавная буква. Пользователи и результаты хранятся в SQLite (`data/infotrainer.db`).
